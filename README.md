## Run locally
Open `index.html` in a browser, or run:

```bash
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```

## Deploy on GitHub Pages
1. Push this folder to GitHub.
2. Open repository Settings.
3. Go to Pages.
4. Choose the branch and root folder.
5. Save.
